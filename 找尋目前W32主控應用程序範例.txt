Windows 的 PID 4 不是一般的應用程式，而是 System (NT Kernel & System)。

這表示 44374 並不是直接由 iisexpress.exe 或 w3wp.exe Listen，而是由 HTTP.sys 接管。

這種情況很常見於：

ASP.NET Framework
IIS
HTTP.sys
Web API
WCF
URL Reservation (netsh http add urlacl)
